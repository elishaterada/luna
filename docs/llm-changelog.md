## 2026-10-15 — Replace saved Live View with ProseMirror

**Request:** Replace the existing Live View editor with ProseMirror and bring over the remaining functionality after evaluating the separate trial.

**Implementation:** Saved Live View now uses the unmodified pinned ProseMirror packages behind a small native adapter. ## 2026-10-15 — Full URL display workflow in the ProseMirror trial

**Request:** Build URL paste, Mention, Bookmark, and Embed workflows in the existing ProseMirror prototype, including display conversion, metadata, Undo/Redo, and Markdown reopening.

**Implementation:** Added a separate document/Markdown module (`note-model.js`) and a ProseMirror link plugin/node-view module (`links.js`). Pasting a valid web URL or iframe snippet inserts a normal link and opens the five Display as choices: Mention, Linked Text, Plain Text, Bookmark, Embed Site. Mentions are inline atoms; Bookmark/Embed items are block atoms. Conversions use a single native ProseMirror transaction and model selection, with history boundaries isolating each conversion from subsequent typing. Block insertion uses ProseMirror's fitting/splitting logic to retain surrounding paragraphs, headings, and list content. Clicking a Mention/link or a card's Display as control reopens the menu; Arrow Up/Down, Enter, Escape and native field Tab/Select All work. Edit Link changes title/URL and returns body typing outside the link; native copy/open actions validate URLs; remove converts inline links to plain text or removes a block. Literal paste and code destinations bypass URL conversion.

**Previews / persistence:** Reused the existing Swift `LinkMetadata` and `EmbedResolver` behind a weak, main-frame-only prototype bridge. A page-session token rejects stale replies. Titles, descriptions, favicons, preview images, and resolved player URLs live in a view cache, outside the ProseMirror document and history. Node views update only their own preview; late metadata does not move selection or create Undo steps. Embed frames are sandboxed; Open original remains available for providers that block framing. Export Markdown and Open Markdown use explicit native file dialogs and a 2 MB UTF-8 limit, independent of Luna's saved notes. Reopen Markdown serializes/parses into fresh editor state without page navigation. `[URL]`, `[Mention]`, `[Bookmark]`, and `[Embed]` survive export/import; legacy `[Preview]` imports as Bookmark. No automatic saved-note/recovery writes were added.

**Follow-up corrections during verification:** Native embed interaction exposed the need to let clipboard/history shortcuts belong to a focused iframe, rather than falling back to the background workspace. The prototype still has no pre-load input buffering. A strict first-export/reparse string comparison also exposed existing CommonMark normalization of whitespace at newly split block edges; the check now verifies stable canonical reopening, display syntax and retained surrounding words rather than claiming byte-exact Markdown. The normalizations remain an explicit limitation. The URL example now starts empty, and the editor/source panes scroll separately with the build footer kept visible.
